# Sistema de Gestión de Pedidos - Programación II

## Integrante

* Nombre: Francisco Bultynch

## Descripción

Aplicación desarrollada en Java para la gestión de categorías, productos, usuarios y pedidos.

El sistema permite realizar operaciones CRUD (crear, listar, editar y eliminar) sobre las entidades principales y gestionar pedidos con múltiples productos, calculando automáticamente el total mediante una interfaz.

## Funcionalidades

### Categorías

* Crear categorías.
* Listar categorías.
* Modificar categorías.
* Eliminar categorías.

### Productos

* Crear productos.
* Listar productos.
* Modificar productos.
* Eliminar productos.

### Usuarios

* Crear usuarios.
* Listar usuarios.
* Modificar usuarios.
* Eliminar usuarios.

### Pedidos

* Crear pedidos.
* Agregar uno o varios productos.
* Calcular el total del pedido.
* Actualizar estado del pedido.
* Actualizar forma de pago.
* Eliminar pedidos (baja lógica).
